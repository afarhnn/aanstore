# Frontend (Flutter) - brief scaffold

Project created with Flutter. This folder contains a minimal app stub to start UI development. Open in VS Code / Android Studio and run `flutter pub get` then `flutter run`.

Files:
- lib/main.dart — entry point with basic routes: login, dashboard, products, pos

Note: full Flutter project files (android/ios/web) are omitted to keep scaffold small; run `flutter create frontend` locally if you want the full project generated and I can push later.
